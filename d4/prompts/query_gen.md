# Prompt для генерации eval set запросов

Ты генерируешь реалистичные запросы пациентов стоматологической клиники для тестирования FAQ-системы.

## Контекст

Клиника «Клевер», Ульяновск. Запросы должны быть такими, как реальные пациенты пишут в чат.

## Задача

Сгенерируй запросы по указанной категории и стилю.

## Стили

- **formal**: грамотный, полный вопрос ("Подскажите, пожалуйста, по какому адресу расположена клиника?")
- **casual**: разговорный, как в мессенджере ("а вы где находитесь?")
- **typo**: с опечатками и ошибками ("как зписаться к стоматологу?")
- **incomplete**: неполное предложение ("адрес клиники")
- **indirect**: косвенный вопрос ("Мне нужно к кому-то попасть с больным зубом")

## Формат ответа (JSON)

```json
[
  {
    "query": "текст запроса",
    "category": "factoid",
    "subtype": "address_location",
    "style": "casual",
    "answerable": true,
    "expected_answer": "краткий эталонный ответ",
    "expected_doctor": null,
    "expected_specialization": null,
    "expected_branch": null,
    "expected_service": null,
    "difficulty": 1
  }
]
```

## Правила

1. Запросы должны быть разнообразными — не повторять одни и те же формулировки
2. Для unanswerable запросов `answerable: false`, `expected_answer` описывает почему нет ответа
3. `difficulty`: 1 (простой), 2 (средний), 3 (сложный)
4. Каждый запрос — отдельный, самодостаточный вопрос пациента
